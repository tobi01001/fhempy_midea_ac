# fhempy_midea_ac

This repository is the home for the Midea air-conditioner module for
[fhempy](https://github.com/fhempy/fhempy). It is intended to store, distribute,
and further develop the module as it matures.

## Current state

This repository is currently in the early setup stage. It contains the project
license and documentation, but the module implementation files are not yet added.
When the module is ready, the expected files are:

- `manifest.json` — module metadata for fhempy
- `midea_ac.py` — the Midea air-conditioner module implementation

The repository is meant to be the place where the module is developed and
maintained independently, with updates to the manifest and implementation kept
in sync as features and compatibility details evolve.

## Development

Add the actual module files here as they are created and updated. Include
relevant usage notes, configuration details, and compatibility information with
