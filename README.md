# fhempy_midea_ac

This repository is the home for the Midea air-conditioner module for
[fhempy](https://github.com/fhempy/fhempy). It is intended to make the module
easy to distribute and provide a place to maintain and develop it independently.

## Expected module files

Add these files to the repository to distribute the module:

- `manifest.json` — module metadata used by fhempy.
- `midea_ac.py` — the Midea air-conditioner module implementation.

Keep the manifest and implementation in sync when changing module metadata or
behavior. Add usage and configuration details here as the module is developed.

## Development

Make changes to the module and its manifest in this repository, and include
relevant usage or compatibility notes with changes that affect users.
